# Star Therapeutics

> Star Therapeutics is a clinical-stage biotechnology company in South San Francisco, California,
> developing best-in-class antibody therapies in hematology and immunology under a hub-and-spoke
> model. Each spoke pursues a distinct area of novel biology and advances a single antibody across
> multiple related indications — a "pipeline-in-a-product" strategy. Its named spokes are Vega
> Therapeutics (VGA039, a first-in-class anti-Protein S monoclonal antibody for von Willebrand
> disease and other bleeding disorders) and Electra Therapeutics (ELA-026, targeting SIRP proteins
> in secondary hemophagocytic lymphohistiocytosis). Star Therapeutics runs NO developer program and
> publishes NO product API, developer portal, API documentation or SDKs. The only machine-readable
> surface reachable without credentials is the WordPress REST content API behind
> star-therapeutics.com, described below.

## What an agent can actually do here

There is one API: a read-only WordPress REST content API. It requires no credentials. It serves the
company's news archive, corporate pages and media library. It does NOT expose clinical trial data,
pipeline data, patient data, or anything about VGA039 or ELA-026 beyond what is written in the
public press releases.

Base URL: https://star-therapeutics.com/wp-json

- [REST API index](https://star-therapeutics.com/wp-json/): 491 routes across 31 namespaces; the
  authoritative live route table.
- [News posts](https://star-therapeutics.com/wp-json/wp/v2/posts): 28 published items,
  2022-02-16 to 2026-07-06. The single highest-value collection.
- [Pages](https://star-therapeutics.com/wp-json/wp/v2/pages): 11 corporate pages.
- [Media](https://star-therapeutics.com/wp-json/wp/v2/media): 661 attachments.
- [Categories](https://star-therapeutics.com/wp-json/wp/v2/categories): Press Release (20),
  News Coverage (7), Presentations (1), Our Perspective (0), Uncategorized (0).
- [Search](https://star-therapeutics.com/wp-json/wp/v2/search?search=VGA039): cross-content search.
- [oEmbed](https://star-therapeutics.com/wp-json/oembed/1.0/embed): oEmbed 1.0 provider endpoint.

Conventions: page/per_page pagination (per_page max 100), X-WP-Total and X-WP-TotalPages response
headers, RFC 8288 Link header for next/prev, `_fields` to trim the payload, `_embed` to inline
related objects. Errors are the WordPress envelope `{code, message, data:{status}}` — NOT RFC 9457.
No rate-limit headers; robots.txt asks for a 10-second crawl delay and the Cloudflare edge will
403 a non-browser user agent that requests HTML pages too quickly.

## What is gated — do not assume otherwise

- `/wp/v2/users` → 401. Author records are not readable; the `author` id on every post is a
  dangling reference. Use the inlined `author_info` object instead.
- `/wp/v2/settings`, `/wp/v2/menus`, `/wp/v2/themes`, `/wp/v2/plugins`, `/wp/v2/block-types`,
  `/wp/v2/font-collections`, `/wp/v2/icons` → 401.
- `/wp-json/jet-engine/v1/mcp` and `/wp-json/jet-engine/v1/mcp-tools` → 401. A JetEngine MCP
  server IS registered on this site, but a JSON-RPC `tools/list` POST returns
  `rest_forbidden`. This is a plugin-default administrative surface bound to an authenticated
  WordPress user — it is NOT an agent endpoint Star Therapeutics publishes for you to call.
- `/wp-json/wp-abilities/v1/*` → 401. The WordPress Abilities API is registered and entirely gated.
- Every write route (POST/PUT/PATCH/DELETE) requires an authenticated WordPress user.
